# Kagaz Ki Kashti — Final Workflow

## Exact workflow

1. Elegant event-title card.
2. User taps **OPEN INVITATION**.
3. Card disappears and Jagjit Singh Ji's supplied image fills the screen.
4. The newly supplied audio starts immediately from that tap.
5. **SCROLL DOWN** appears at the bottom.
6. User scrolls/clicks down to the complete event explanation.
7. Details continue through date, venue, RSVP and Google Maps.

## GitHub Pages

Upload the files exactly as they are, including the entire `assets` folder.
Do not rename the files or move the assets outside the `assets` folder.

GitHub:
Settings → Pages → Deploy from a branch → main → / (root).

If an older version is already published, replace/delete the old `index.html`, `style.css`, `script.js`, and `assets` files with these new versions, then commit the changes.

The audio is intentionally started by the Open Invitation button because mobile browsers commonly block autoplay before user interaction.
